## 4. 平台词汇数据的整合规则

每个词条应分清以下类别：
- textbook_word：教材单词表中的词条；
- textbook_phrase：教材列出的词组/固定表达；
- in_text_expression：课文、对话或练习中出现，但不在单词表中的表达；
- extension：主题拓展词；
- exam_extension：中考衔接拓展。

每条教材词汇至少记录：
- book_id、unit_id、教材版次/印次状态；
- 英文词或短语、词性、教材语境义；
- 英式教材拼写及可接受变体（如有）；
- 音标（来源可靠并经复核后才填）；
- 教材位置/栏目/页码（未核实则留空，禁止猜测）；
- 来源类型、核验状态、核验日期。

判题规则：
- “按教材拼写默写”模式：明确提示目标拼写，区分教材标准形式与其他规范变体。
- “英语表达/语境运用”模式：不因英美拼写差异自动判错；结合词性、语境和词义判断。
- 不允许只因中文释义相近就把不同词条混为同义词。
- 不把拓展词混入教材必学词统计。

## 5. 版本与质量门槛

1. 未核验版权页/ISBN/印次的册次不得标记为“最新版已确认”。
2. 目录匹配不等于词汇表匹配；词汇表匹配不等于逐课内容完整。
3. 每册逐单元完成目录、教材词表、课文语境、短语四项核对后，才可标记“教材词汇核验完成”。
4. 原有学习记录必须保留；词库更新采用稳定词条 ID 和迁移映射，不清空本地数据。
5. 不把整本教材 PDF、整页扫描或未获许可的第三方下载包复制进公开网站。优先链接官方资源，本站只保存必要的自编学习数据、简短词条事实和合规教学例句。
