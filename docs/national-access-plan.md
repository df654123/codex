# 全国访问能力升级计划

更新日期：2026-11-06

## 当前部署基线

- 当前公开学习站：GitHub Pages（df654123/codex）。
- 当前页面已通过 GitHub Pages 部署工作流。
- 现有 PWA / Service Worker 离线能力已通过 GitHub Actions 自动化测试：390px Chrome、在线缓存、断网重启、词汇练习及本机学习记录刷新。
- 这些结果证明测试环境中的页面与离线流程，不等于中国各省、各运营商均已实测。
- 现有记录存储在当前浏览器本机；跨设备/跨账号同步尚未实现。

## 分阶段决策

### 阶段 A：维持现有免费入口（当前）

1. 保留现有 GitHub Pages 地址和仓库，不迁移、不删除、不更改可见性。
2. 保持当前离线缓存、网络检测页和家庭 Wi-Fi 备用方案。
3. 通过不同地区的真实用户反馈收集访问数据；记录省份/城市、运营商、网络类型、浏览器、时间、首页/课程/词汇/保存结果。不要收集精确地址、姓名、学生身份或学习内容。
4. 每次发布后自动检查首页、课程数据、词汇提交、记录刷新和 Service Worker 缓存。

### 阶段 B：国内访问加速（需先完成域名和备案准备）

腾讯云官方文档说明：接入中国境内或全球 CDN 的加速域名须完成 ICP 备案；境外加速区域不要求备案。境内 CDN 建议源站位于境内，以降低跨境回源失败或延迟风险。

建议顺序：
1. 由账号所有者选择并注册一个自有域名（费用购买前先确认）。
2. 确认网站主体、备案主体和实际用途，按主管部门/云厂商要求完成 ICP 备案；不要假设实名认证等于 ICP 备案。
3. 在测试子域名上配置国内静态源站与 CDN，设置 HTTPS、缓存策略、回源、错误页和回滚。
4. 验证域名所有权、证书、CDN 命中率、资源完整性及 Service Worker 更新。
5. 通过验收后再将自有域名设为主入口；GitHub Pages 继续保留作回滚入口。

### 阶段 C：长期平台能力

- 独立安全后端：学生/教师/家长角色、跨设备同步、账号恢复与权限控制。
- 数据保护：最小化采集、传输加密、访问控制、备份与删除策略。
- 教材和题库：标注教材版本、册次、单元、知识点、来源及授权；避免将非授权教材全文或试题直接公开。
- 全国推广前：隐私政策、未成年人个人信息保护、内容审核和运营责任评估。

## 费用与授权边界

- 当前阶段不购买域名、云服务器或 CDN 套餐。
- 国内 CDN 的具体费用取决于产品、流量、请求数和区域，应在控制台报价后由账号所有者确认。
- 不公开任何私有仓库，不修改原 Sites 项目，不迁移真实学生记录。
- 任何付费、域名注册、备案主体信息提交或隐私数据后端上线，均先向账号所有者确认。
