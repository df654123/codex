# 短视频生产工作流

## 阶段 1：定位与选题

- 明确账号定位：面向谁、解决什么问题、用什么风格表达。
- 建立选题池：热点、用户问题、竞品拆解、行业知识、个人经验。
- 标记优先级：按受众痛点、传播潜力、制作成本和商业价值排序。

## 阶段 2：脚本与分镜

每条视频至少准备以下内容：

- 标题：用于平台发布和内部识别。
- 开头钩子：前 3 秒说明冲突、结果或利益点。
- 主体结构：用 3 到 5 个关键点讲清楚内容。
- 结尾动作：引导关注、评论、收藏、私信或购买。
- 分镜表：镜头编号、画面、台词、字幕、音效、时长。

## 阶段 3：素材准备

- 真人拍摄：口播、产品展示、场景演示、采访。
- 屏幕录制：教程类、软件类、案例拆解类内容。
- 素材库：B-roll、音效、音乐、贴纸、动态图形。
- AI 生成：封面、背景、插画、转场、补充镜头。

## 阶段 4：剪辑包装

- 粗剪：先保证信息完整和逻辑顺畅。
- 精剪：删掉停顿、废话和重复信息。
- 字幕：保证可读性，重点词可以加粗或变色。
- 音频：人声清晰，背景音乐不压过人声。
- 包装：统一封面、字幕、片尾和品牌元素。

## 阶段 5：发布与复盘

发布后记录以下数据：

- 发布时间。
- 标题与封面版本。
- 播放量。
- 完播率。
- 点赞、评论、收藏、转发。
- 涨粉数。
- 转化结果。
- 可复用经验与下次优化点。
