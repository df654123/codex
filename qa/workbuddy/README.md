# 七年级4班 WorkBuddy · 负责人匿名安全核查

本目录存放公开网站**只读验收**。完整的后台业务和数据库仍由 WorkBuddy 内部开发项目负责，当前 GitHub 仓库未取得其源码与后台权限。

## 分工与验收门槛
- A 身份与权限：班主任、任课教师、学生/家长、大屏的角色都必须由**服务器授权**而非前端下拉框控制。未经授权不得呈现真实名册、成绩、家庭信息。
- B 数据：服务器应对教师记录返回保存确认。断网时明确区别本机暂存、待同步、已同步；同一操作重试不重复记账。
- C 多人协作：两个不同账号、两个独立设备保存、读取并验证记录归属和撤权。
- D 手机网络：Safari/Chrome、校园网、家庭 Wi-Fi、手机流量全部跑完登录、保存、刷新、退出、重新登录。
- E 数据恢复：每日备份、隔离环境恢复演练、版本回滚和失败处理。
- F 负责人：只认源代码、完整测试日志、真实部署结果；任何一条阻断性失败都不签核。

## 本次 CI 检查说明
匿名 Chromium 不登录、不写入、不点击个人记录，也不采集、不输出或保存学生姓名、名单、令牌、Cookie、截图。仅报告 HTTP 响应、权限相关界面的是否渲染等**布尔指标**。网页声明“云同步已开启”不构成实际同步证据。

如果发现匿名页面显示角色选择器、名册入口及班级数据，判为**需要排查的潜在隐私风险**，不等于已通过独立身份验证的越权漏洞复现；若页面仅呈现演示数据，也需要明确区分。

仅 GitHub 代码在场不能证明 WorkBuddy 智能体任务完成。检查 WorkBuddy 开发进度需要接通其原项目编辑页面。
