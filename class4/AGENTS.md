## 职责与交接
- 源码核验：固定提交、许可证、锁文件、部署文件。输出 provenance 与源码校验和。
- 可靠性：积分写入/撤销事务、重试幂等、离线队列。每个缺陷先复现再修复。
- 权限安全：教师身份、班级边界、停用会话、学生与只读大屏。测试仅使用隔离虚构数据。
- 构建测试：完整安装、生产构建、真实 SQLite 和 HTTP 测试。不得把模拟测试或没实现的测试步骤写成通过。
- 项目负责人：复核每条原始日志、未通过项与部署权限；决定是否可发布。

这些是任务角色；本次自动并行执行的是 GitHub Actions 作业，不是独立 GPT 员工。不要声称已派发不可用的子代理。
